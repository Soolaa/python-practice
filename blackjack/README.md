# Blackjack Game 🃏

یک بازی ساده‌ی بلک‌جک (۲۱) به‌صورت متنی (Console)، بین کاربر و کامپیوتر.

## قوانین بازی

- به هر بازیکن دو کارت داده می‌شود.
- کاربر می‌تواند کارت جدید بگیرد (`y`) یا پاس بدهد (`n`).
- اگر مجموع امتیاز از ۲۱ بیشتر شود، آن بازیکن می‌بازد.
- کامپیوتر تا زمانی که امتیازش کمتر از ۱۷ باشد، کارت می‌گیرد.
- اگر مجموع دو کارت اول دقیقاً ۲۱ شود، «بلک‌جک» است و همان لحظه برنده می‌شود.
- کارت آس (A) بسته به شرایط می‌تواند ۱۱ یا ۱ امتیاز حساب شود.

## اجرای برنامه

```bash
python blackjack.py
```

## چیزهایی که در این تمرین یاد گرفتم / تمرین کردم

- کار با لیست‌ها و توابع `random.choice`
- نوشتن توابع جدا برای منطق بازی (`deal_card`, `calculate_score`, `compare`)
- استفاده از حلقه‌ی `while` برای کنترل جریان بازی
- گرفتن ورودی از کاربر با `input()`
