# Higher or Lower Game 📱

یک بازی ساده‌ی **Higher or Lower** که در آن دو اکانت محبوب اینستاگرام با یکدیگر مقایسه می‌شوند و کاربر باید حدس بزند کدام اکانت دنبال‌کننده (Follower) بیشتری دارد.

## قوانین بازی

* در هر مرحله، دو اکانت اینستاگرام به کاربر نمایش داده می‌شوند:

  * **A**
  * **B**
* اطلاعاتی مانند نام، توضیحات و کشور هر اکانت نمایش داده می‌شود.
* کاربر باید حدس بزند کدام اکانت دنبال‌کننده‌ی بیشتری دارد.
* اگر پاسخ درست باشد:

  * امتیاز کاربر (`score`) یک واحد افزایش پیدا می‌کند.
  * بازی ادامه پیدا می‌کند.
* اگر پاسخ اشتباه باشد:

  * بازی تمام می‌شود.
  * امتیاز نهایی کاربر نمایش داده می‌شود.
* اکانت **B** در مرحله‌ی بعد به اکانت **A** تبدیل می‌شود.

## اجرای برنامه

```bash
python main.py
```

## فایل‌ها

* `main.py` — منطق اصلی بازی
* `instagram_top_accounts.py` — شامل اطلاعات اکانت‌های اینستاگرام مانند نام، توضیحات، کشور و تعداد دنبال‌کنندگان

## چیزهایی که در این تمرین یاد گرفتم / تمرین کردم

* استفاده از `random.choice()` برای انتخاب تصادفی اکانت‌ها
* کار با لیست و Dictionary برای دسترسی به اطلاعات اکانت‌ها
* نوشتن تابع (`function`) برای نمایش اطلاعات هر اکانت
* استفاده از `return` برای برگرداندن نتیجه‌ی مقایسه
* استفاده از `while loop` برای ادامه دادن بازی تا زمانی که کاربر پاسخ اشتباه بدهد
* استفاده از شرط `if` برای جلوگیری از انتخاب یک اکانت تکراری
* تبدیل ورودی کاربر به حروف بزرگ با `.upper()`
* نگهداری و افزایش امتیاز کاربر با متغیر `current_score`
* استفاده از یک متغیر Boolean برای کنترل ادامه یا پایان بازی

## منطق بازی

در ابتدای بازی، یک اکانت به صورت تصادفی به عنوان `account_b` انتخاب می‌شود.

در هر دور از بازی:

1. `account_b` قبلی به `account_a` تبدیل می‌شود.
2. یک اکانت تصادفی جدید به عنوان `account_b` انتخاب می‌شود.
3. اطلاعات دو اکانت به کاربر نمایش داده می‌شود.
4. کاربر انتخاب می‌کند که **A** یا **B** دنبال‌کننده‌ی بیشتری دارد.
5. تعداد دنبال‌کنندگان دو اکانت با هم مقایسه می‌شود.
6. در صورت پاسخ درست، امتیاز افزایش پیدا می‌کند و بازی ادامه پیدا می‌کند.
7. در صورت پاسخ اشتباه، بازی پایان پیدا می‌کند و امتیاز نهایی نمایش داده می‌شود.
